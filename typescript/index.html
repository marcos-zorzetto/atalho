TypeScript com o Atalho

O Atalho vem com tipos completos: o editor completa nomes de funções, verifica os dados do estado e sabe o formato de cada evento.

1. Descarregue os tipos

Guarde o ficheiro atalho.d.ts na pasta do seu projeto (por exemplo, em tipos/). Descreve o objeto global Atalho e todos os eventos at:*.

Terminal
curl -o tipos/atalho.d.ts https://cdn.jsdelivr.net/gh/marcos-zorzetto/atalho@1/atalho/atalho.d.ts

E garanta que o tsconfig.json inclui a pasta:

tsconfig.json
{
  "compilerOptions": {
    "target": "ES2022",
    "lib": ["ES2022", "DOM", "DOM.Iterable"],
    "strict": true,
    "noEmit": true
  },
  "include": ["src", "tipos"]
}

2. Estado tipado

Descreva o formato dos dados com uma interface. O TypeScript passa a avisar se escrever um campo errado ou se esquecer de um.

TypeScript
interface Produto {
  id: number;
  nome: string;
  preco: number;
}

interface Carrinho {
  itens: Produto[];
  readonly total: number;
  adicionar(produto: Produto): void;
}

const carrinho = Atalho.estado<Carrinho>("carrinho", {
  itens: [],
  get total(): number {
    return this.itens.reduce((soma, item) => soma + item.preco, 0);
  },
  adicionar(produto) {
    this.itens = [...this.itens, produto]; // produto já é do tipo Produto
  },
}, { salvar: true });

carrinho.adicionar({ id: 1, nome: "T-shirt", preco: 59.9 });
console.log(Atalho.formatar.moeda(carrinho.total)); // "59,90 €"

3. Eventos tipados

Os eventos do Atalho entram no mapa de eventos do navegador, por isso evento.detail já vem com o tipo certo.

TypeScript
const formulario = document.querySelector<HTMLFormElement>("#cadastro")!;

formulario.addEventListener("at:enviar", (evento) => {
  const { dados, botao } = evento.detail; // dados: Record<string, FormDataEntryValue>
  botao?.setAttribute("aria-busy", "true");
});

document.addEventListener("at:cep", (evento) => {
  console.log(evento.detail.localidade, evento.detail.uf); // tipos do ViaCEP
});

4. Pedidos tipados

TypeScript
interface Cliente {
  id: number;
  nome: string;
}

try {
  const cliente = await Atalho.requisitar<Cliente>("/api/clientes", {
    metodo: "POST",
    corpo: { nome: "Ana" },
  });
  Atalho.notificar(`${cliente.nome} registada`, { tipo: "sucesso" });
} catch (erro) {
  if (erro instanceof Error) Atalho.notificar(erro.message, { tipo: "perigo" });
}

5. Com Vite ou outro bundler

Carregue o Atalho pelo HTML (CDN) e use os tipos normalmente nos seus ficheiros .ts. O Atalho não precisa de ser importado: cria window.Atalho sozinho.
