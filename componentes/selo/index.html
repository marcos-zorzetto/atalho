Selos e etiquetas

Selos mostram o estado (Pago, Pendente, Novo). Etiquetas são filtros ou tags que a pessoa pode remover.

HTML
Padrão usado emGitHub (labels de issues)Stripe (estado do pagamento)Airbnb (filtros ativos)

Quando usar

  • Selo: estado de um item. Etiqueta: filtros aplicados e tags editáveis.

Como funciona

Selos são só visuais. Na etiqueta, um botão com data-at-fechar remove a etiqueta da página.

Exemplos

Estado

Rascunho Novo Pago A aguardar Cancelado Enviado -25%
Editar e testar 
<div class="at-linha">
  <span class="at-selo">Rascunho</span>
  <span class="at-selo at-primario">Novo</span>
  <span class="at-selo at-sucesso at-ponto">Pago</span>
  <span class="at-selo at-aviso at-ponto">A aguardar</span>
  <span class="at-selo at-perigo at-ponto">Cancelado</span>
  <span class="at-selo at-info">Enviado</span>
  <span class="at-selo at-destaque">-25%</span>
</div>

Filtros aplicados

Portes grátis Até 500 € Novo
Editar e testar 
<div class="at-linha">
  <span class="at-etiqueta">Portes grátis <button data-at-fechar aria-label="Remover filtro Portes grátis">×</button></span>
  <span class="at-etiqueta">Até 500 € <button data-at-fechar aria-label="Remover filtro Até 500 €">×</button></span>
  <span class="at-etiqueta">Novo <button data-at-fechar aria-label="Remover filtro Novo">×</button></span>
</div>

Referência

NomeTipoO que faz
at-seloclasseCores: at-primario, at-sucesso, at-aviso, at-perigo, at-info, at-destaque. Acrescente at-ponto para uma bolinha.
at-etiquetaclasseTag com botão de remover (data-at-fechar).

Acessibilidade

  • Não dependa só da cor: o texto do selo precisa de dizer o estado.
