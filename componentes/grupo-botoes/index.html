Grupo de botões e botão fechar

Botões colados que funcionam como um conjunto (alinhar texto, escolher visualização) e o botão "×" padrão para fechar caixas.

HTMLJavaScript
Padrão usado emGoogle Docs (alinhamento)Windows Explorer (lista ou grelha)Bootstrap (button group, close button)

Quando usar

  • Opções relacionadas lado a lado, como Lista/Grelha ou Dia/Semana/Mês.
  • O botão fechar em alertas, cartões e painéis personalizados.

Evite

  • Escolher uma opção num formulário: o segmentado das Abas ou rádios comunicam melhor.

Como funciona

Envolva .at-botao em .at-grupo-botoes. Para botões que ligam e desligam, use aria-pressed="true" no ativo. O .at-fechar é um botão quadrado e discreto com "×": use sempre com aria-label.

document.querySelectorAll('[aria-label="Visualização"] .at-botao').forEach((botao, _, todos) => {
  botao.addEventListener("click", () => todos.forEach((b) => b.setAttribute("aria-pressed", String(b === botao))));
});

Botão fechar

Temos novidades no seu painel.
Editar e testar 
<div class="at-superficie at-linha at-entre" style="max-width: 420px" id="aviso-novidade">
  <span>Temos novidades no seu painel.</span>
  <button class="at-fechar" aria-label="Fechar aviso" data-at-fechar="#aviso-novidade">×</button>
</div>

Referência

NomeTipoO que faz
at-grupo-botoesclasseJunta os botões, com cantos só nas pontas.
aria-pressed="true"atributoBotão ligado (destacado).
at-fecharclasseBotão "×" para fechar.

Acessibilidade

  • Envolva o grupo num role="group" com aria-label, para o leitor de ecrã anunciar o conjunto.
  • Botões só com ícone ou "×" precisam de aria-label.
