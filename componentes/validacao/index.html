Validação de formulário

Mensagens de erro claras, em português, no lugar certo e na hora certa. Sem biblioteca extra, com a validação nativa do navegador.

HTMLJavaScriptTypeScriptPHP
Padrão usado emGOV.UK Design System (padrão de mensagens de erro)Stripe (validação ao sair do campo)Google (registo de conta)
Suporte dos navegadoresConstraint validation API · Em todos os navegadoresinput (event) · Em todos os navegadores

Quando usar

  • Em todos os formulários que a pessoa envia.

Evite

  • Mostrar erro enquanto a pessoa ainda está a escrever pela primeira vez. Espere que ela saia do campo.

Como funciona

Adicione data-at-validar ao <form> e use os atributos nativos: required, type="email", minlength, pattern, min, max. O Atalho troca as mensagens do navegador (que variam e às vezes vêm em inglês) por mensagens consistentes em português. O erro aparece quando a pessoa sai do campo ou tenta enviar, e desaparece assim que ela corrige. Se o formulário não tiver action, o envio não recarrega a página: recebe os dados no evento at:enviar, prontos a enviar para uma API.

document.querySelector("#form-conta").addEventListener("at:enviar", (evento) => {
  const { dados, botao } = evento.detail;
  botao.setAttribute("aria-busy", "true");

  // Aqui enviaria os dados para a sua API:
  // await Atalho.requisitar("/api/contas", { metodo: "POST", corpo: dados });
  setTimeout(() => {
    botao.removeAttribute("aria-busy");
    Atalho.notificar("Conta criada para " + dados.email, { tipo: "sucesso", titulo: "Tudo certo!" });
  }, 1200);
});
const formulario = document.querySelector<HTMLFormElement>("#form-conta")!;

formulario.addEventListener("at:enviar", async (evento) => {
  const { dados, botao } = evento.detail; // dados: Record<string, FormDataEntryValue>
  botao?.setAttribute("aria-busy", "true");
  try {
    await Atalho.requisitar<{ id: number }>("api/cadastro.php", { metodo: "POST", corpo: dados });
    Atalho.notificar("Conta criada!", { tipo: "sucesso" });
  } catch (erro) {
    if (erro instanceof Error) Atalho.notificar(erro.message, { tipo: "perigo" });
  } finally {
    botao?.removeAttribute("aria-busy");
  }
});

Referência

NomeTipoO que faz
data-at-validaratributoNo <form>. Liga a validação em português.
data-msg-obrigatorio / data-msg-formatoatributoTroca a mensagem predefinida de um campo.
data-at-igual="#outro"atributoExige o mesmo valor de outro campo (confirmar palavra-passe ou e-mail).
data-at-acao="estado.metodo"atributoNo <form>: chama a ação com os dados quando for válido.
at:enviareventoFormulário válido. detail.dados tem os valores; detail.botao, o botão usado.
at:invalidoeventoTentou enviar com erro. detail.campos lista os campos inválidos.

Acessibilidade

  • O campo inválido recebe aria-invalid="true" e aria-describedby a apontar para a mensagem, por isso o leitor de ecrã lê o erro.
  • Ao enviar com erro, o foco vai para o primeiro campo errado.
