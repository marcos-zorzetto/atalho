Cartão

Caixa que agrupa informações de um mesmo assunto: artigo, resumo, configuração, item clicável.

HTML
Padrão usado emVercel (cartões de projeto)Medium (cartões de artigo)Stripe (secções de configuração)
Suporte dos navegadoresaspect-ratio · Em todos os navegadoresobject-fit · Em todos os navegadores

Quando usar

  • Listas de coisas parecidas (artigos, projetos).
  • Separar secções de uma página de configurações.

Como funciona

Combine as partes de que precisar: imagem, cabeçalho, corpo e rodapé. Quando o cartão inteiro leva a outra página, use <a class="at-cartao">: o cartão ganha efeito ao passar o rato.

  • Num cartão clicável, o texto do link é o conteúdo do cartão: mantenha o título no começo.
