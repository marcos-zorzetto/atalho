Código de verificação

Seis caixinhas para o código recebido por SMS ou e-mail. Avança sozinho, aceita colar e preenche-se automaticamente a partir do SMS no telemóvel.

HTMLJavaScript
Padrão usado emWhatsApp (confirmação de número)Revolut e bancos (token)Google (verificação em duas etapas)
Suporte dos navegadoresinput (event) · Em todos os navegadoresClipboard events · Em todos os navegadores

Quando usar

  • Confirmação de telefone, e-mail ou login em duas etapas.

Como funciona

Envolva os inputs em .at-codigo com data-at="codigo". O primeiro campo recebe autocomplete="one-time-code", que faz com que o iPhone e o Android sugiram o código do SMS. Quando todos os dígitos estão preenchidos, o evento at:codigo traz o valor completo.

Exemplo

Confirme o seu número

O código certo é 123456. Teste também colar.

Enviámos um código por SMS para +351 9•• ••• 321.

Editar e testar 
<div class="at-pilha" style="--at-gap: 12px">
  <p class="at-mb-0">Enviámos um código por SMS para <strong>+351 9•• ••• 321</strong>.</p>
  <div class="at-codigo" data-at="codigo" id="codigo-sms">
    <input><input><input><input><input><input>
  </div>
  <button class="at-botao at-link" type="button">Reenviar código em 30 s</button>
</div>
const codigo = document.querySelector("#codigo-sms");

codigo.addEventListener("at:codigo", (evento) => {
  if (evento.detail.valor === "123456") {
    Atalho.notificar("Número confirmado!", { tipo: "sucesso" });
  } else {
    codigo.setAttribute("aria-invalid", "true");
    Atalho.notificar("Código incorreto. Verifique o SMS.", { tipo: "perigo" });
  }
});

Referência

NomeTipoO que faz
data-at="codigo"atributoLiga o comportamento.
at:codigoeventoTodos os dígitos preenchidos. detail.valor tem o código.

Acessibilidade

  • Cada caixinha recebe um nome (Dígito 1 de 6...). Para marcar erro, coloque aria-invalid="true" no .at-codigo.
