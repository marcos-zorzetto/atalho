Lista agrupada (list group)

Lista em caixa, com itens separados por linha: links de menu, configurações, contactos ou passos numerados.

HTML
Padrão usado emDefinições do iPhoneConfigurações do GitHubBootstrap (list group)
Suporte dos navegadoresFlexbox · Em todos os navegadores

Quando usar

  • Menus de configurações e listas de opções clicáveis.
  • Listas curtas com um selo ou ação no fim de cada linha.

Evite

  • Dados com várias colunas: use a Tabela.
  • Navegação principal do site: use a Barra ou o Menu lateral.

Como funciona

Uma .at-lista-grupo com itens .at-lista-item. Os itens podem ser texto, links (<a>) ou botões (<button>): links e botões ganham destaque ao passar o rato e foco visível no teclado. O item atual usa aria-current e o desativado, aria-disabled="true". O último elemento do item (selo, número, seta) vai sozinho para a direita.

Referência

NomeTipoO que faz
at-lista-grupoclasseA caixa da lista (ul ou div).
at-lista-itemclasseCada linha. Pode ser li, a ou button.
aria-current="page"atributoMarca o item atual (fica destacado).
aria-disabled="true"atributoItem desativado.
at-numeradamodificadorNumera os itens automaticamente.
at-sem-bordamodificadorSem caixa externa, só as linhas.

Acessibilidade

  • Use <ul> com <li> para o leitor de ecrã anunciar quantos itens existem.
  • O item atual tem aria-current: o leitor de ecrã diz "página atual", não só a cor.
