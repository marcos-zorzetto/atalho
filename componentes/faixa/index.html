Faixa de valores (slider)

Controlo deslizante estilizado, com o valor mostrado ao lado e formatado no idioma e na moeda da página.

HTMLJavaScript
Padrão usado emSimuladores de crédito dos bancos portuguesesAirbnb (filtro de preço)

Quando usar

  • Valores aproximados em que a pessoa experimenta: simulador de crédito, filtro de preço, volume.

Evite

  • Valores exatos (NIF, idade): use um campo de texto.

Como funciona

É um <input type="range"> nativo com a classe at-faixa-entrada. Um <output for="id"> mostra o valor, formatado por data-at-formato (moeda, numero, porcentagem…).

Exemplo

Simulador de crédito

Prestação mensal estimada:

Editar e testar 
<div class="at-cartao" style="max-width: 420px">
  <div class="at-cartao-corpo at-pilha">
    <div class="at-campo">
      <div class="at-linha at-entre"><label class="at-rotulo" for="valor-emprestimo">De quanto precisa?</label><output for="valor-emprestimo" data-at-formato="moeda"></output></div>
      <input type="range" class="at-faixa-entrada" id="valor-emprestimo" min="1000" max="30000" step="500" value="8000" data-at-valor="simulador.valor">
    </div>
    <div class="at-campo">
      <div class="at-linha at-entre"><label class="at-rotulo" for="parcelas-emprestimo">Em quantos meses?</label><output for="parcelas-emprestimo"></output></div>
      <input type="range" class="at-faixa-entrada" id="parcelas-emprestimo" min="6" max="48" step="6" value="24" data-at-valor="simulador.parcelas">
    </div>
    <p class="at-mb-0">Prestação mensal estimada: <strong class="at-titulo-4" data-at-texto="simulador.parcela" data-at-formato="moeda"></strong></p>
  </div>
</div>
Atalho.estado("simulador", {
  valor: 8000,
  parcelas: 24,
  // Juros de exemplo: TAN de 9% ao ano (0,75% ao mês, prestação constante)
  get parcela() {
    const juros = 0.0075;
    const n = Number(this.parcelas);
    return (Number(this.valor) * juros) / (1 - (1 + juros) ** -n);
  },
});

Referência

NomeTipoO que faz
at-faixa-entradaclasseNo input type=range.
<output for="id">atributoMostra o valor atual.
data-at-formatoatributoNo input ou no output: moeda, numero, porcentagem.

Acessibilidade

  • Por ser nativo, funciona com as setas do teclado e é anunciado com o valor atual.
