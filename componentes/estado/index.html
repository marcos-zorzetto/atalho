Estado (reatividade)

A ideia central do React, sem React: muda os dados e o ecrã atualiza-se sozinho. É assim que os componentes se conectam.

HTMLJavaScriptTypeScript
Padrão usado emReact (useState e dados imutáveis)Vue e Pinia (estado com ações e getters)Alpine.js (atributos no HTML)
Suporte dos navegadores<template> · Em todos os navegadoreslocalStorage and sessionStorage · Em todos os navegadores

Quando usar

  • Quando várias partes do ecrã mostram o mesmo dado (o número do carrinho na barra e o total na gaveta).
  • Quando dá por si a escrever document.querySelector(...).textContent = ... em vários lugares.

Como funciona

Atalho.estado("nome", { dados, getters, ações }) cria o estado. No HTML, data-at-texto="nome.campo" mostra o valor, data-at-mostrar esconde/mostra, data-at-lista repete um <template>, data-at-valor liga um campo nos dois sentidos e data-at-acao chama uma função. Como no React, para atualizar uma lista crie um array novo (this.itens = [...this.itens, novo]) em vez de usar push: é a troca de valor que avisa o ecrã. Com { salvar: true } os dados sobrevivem ao recarregar a página.

Exemplos

Contador

Passou de 5!
Editar e testar 
<div class="at-linha">
  <button class="at-botao at-icone" data-at-acao="contador.diminuir" aria-label="Diminuir">−</button>
  <strong class="at-titulo-3 at-mb-0 at-numero" data-at-texto="contador.valor" aria-live="polite"></strong>
  <button class="at-botao at-icone" data-at-acao="contador.aumentar" aria-label="Aumentar">+</button>
  <span class="at-selo at-aviso" data-at-mostrar="contador.alto">Passou de 5!</span>
</div>
Atalho.estado("contador", {
  valor: 0,
  get alto() { return this.valor > 5; },
  aumentar() { this.valor++; },
  diminuir() { this.valor = Math.max(0, this.valor - 1); },
});
interface Contador {
  valor: number;
  readonly alto: boolean;
  aumentar(): void;
  diminuir(): void;
}

Atalho.estado<Contador>("contador", {
  valor: 0,
  get alto(): boolean { return this.valor > 5; },
  aumentar() { this.valor++; },
  diminuir() { this.valor = Math.max(0, this.valor - 1); },
});

Lista de tarefas que fica guardada

Adicione tarefas e recarregue a página: elas continuam lá.

Editar e testar 
<form class="at-grupo-entrada" style="max-width: 420px" data-at-acao="tarefas.adicionar">
  <input class="at-entrada" name="texto" placeholder="Nova tarefa" aria-label="Nova tarefa" required autocomplete="off">
  <button class="at-botao at-primario">Adicionar</button>
</form>

<p class="at-texto-suave at-texto-pequeno at-mt-4" data-at-texto="tarefas.resumo"></p>

<ul class="at-pilha" style="--at-gap: 6px; list-style: none; padding: 0; max-width: 420px" data-at-lista="tarefas.itens">
  <template>
    <li class="at-superficie at-linha at-entre" style="padding: 8px 12px">
      <span data-at-campo="texto"></span>
      <button class="at-botao at-fantasma at-pequeno" data-at-acao="tarefas.remover">Concluir</button>
    </li>
  </template>
</ul>
Atalho.estado("tarefas", {
  itens: [{ id: 1, texto: "Estudar o componente Estado" }],
  get resumo() {
    return this.itens.length
      ? Atalho.formatar.plural(this.itens.length, "tarefa pendente", "tarefas pendentes")
      : "Tudo feito por hoje!";
  },
  adicionar(dados, evento) {
    this.itens = [...this.itens, { id: Date.now(), texto: dados.texto }];
    evento.target.reset();
  },
  remover(tarefa) {
    this.itens = this.itens.filter((t) => t.id !== tarefa.id);
  },
}, { salvar: true });
interface Tarefa { id: number; texto: string }

interface Tarefas {
  itens: Tarefa[];
  readonly resumo: string;
  adicionar(dados: { texto: string }, evento: SubmitEvent): void;
  remover(tarefa: Tarefa): void;
}

Atalho.estado<Tarefas>("tarefas", {
  itens: [],
  get resumo(): string {
    return Atalho.formatar.plural(this.itens.length, "tarefa pendente", "tarefas pendentes");
  },
  adicionar(dados, evento) {
    this.itens = [...this.itens, { id: Date.now(), texto: dados.texto }];
    (evento.target as HTMLFormElement).reset();
  },
  remover(tarefa) {
    this.itens = this.itens.filter((t) => t.id !== tarefa.id);
  },
}, { salvar: true });

Referência

NomeTipoO que faz
Atalho.estado(nome, objeto, { salvar })funçãoCria o estado e devolve o objeto reativo.
data-at-texto="nome.campo" + data-at-formatoatributoMostra o valor (formatos: moeda, numero, data, relativo, porcentagem…).
data-at-mostrar / data-at-desabilitaratributoMostra ou desativa conforme o valor. Use ! para negar: "!nome.campo".
data-at-valor="nome.campo"atributoLiga input/checkbox ao estado nos dois sentidos.
data-at-lista="nome.lista" + <template>atributoRepete o template para cada item.
data-at-campo / data-at-atributosatributoDentro do template: texto e atributos vindos do item.
data-at-acao="nome.metodo" + data-at-dadosatributoChama o método. Dentro de lista, recebe o item automaticamente.
Atalho.observar(nome, função)funçãoExecuta algo sempre que o estado mudar. Devolve função para parar.

Acessibilidade

  • Quando uma mudança de estado for importante (total do carrinho), coloque aria-live="polite" no elemento.
