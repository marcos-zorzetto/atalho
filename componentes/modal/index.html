Modal (janela de diálogo)

Janela por cima da página para confirmar algo importante ou preencher um formulário rápido. Abre sem escrever JavaScript.

HTMLJavaScript
Padrão usado emGitHub (eliminar repositório a escrever o nome)Google Drive (partilhar)Stripe (confirmações)
Suporte dos navegadores<dialog> · Em todos os navegadoresInvoker commands · Novo em todos os navegadores:has() · Em todos os navegadores@starting-style · Novo em todos os navegadores

Quando usar

  • Confirmar ações irreversíveis.
  • Formulários curtos que não merecem uma página (renomear, convidar).

Evite

  • Conteúdo longo ou abrir um modal de dentro de outro. Use uma página ou uma gaveta.

Como funciona

É o elemento nativo <dialog>. O botão com commandfor="id" command="show-modal" abre o modal sem nenhuma linha de JavaScript (invoker commands, padrão dos navegadores desde 2025; o Atalho cobre os mais antigos). O navegador trata do foco, da tecla Esc e de bloquear o resto da página; o Atalho fecha ao clicar no fundo e bloqueia o scroll. Botões dentro de <form method="dialog"> fecham o modal e o value do botão fica em dialog.returnValue.

Exemplos

Confirmação simples

Cancelar subscrição?

Continua a ter acesso até 30/11. Depois disso, os seus projetos ficam só de leitura.
Editar e testar 
<button class="at-botao at-perigo" commandfor="modal-sair" command="show-modal">Cancelar subscrição</button>

<dialog class="at-modal at-pequeno" id="modal-sair" aria-labelledby="modal-sair-titulo">
  <form method="dialog">
    <div class="at-modal-corpo">
      <h3 id="modal-sair-titulo" class="at-titulo-4">Cancelar subscrição?</h3>
      <p class="at-texto-suave">Continua a ter acesso até 30/11. Depois disso, os seus projetos ficam só de leitura.</p>
    </div>
    <div class="at-modal-rodape">
      <button class="at-botao at-fantasma" value="manter">Manter subscrição</button>
      <button class="at-botao at-perigo" value="cancelar">Cancelar subscrição</button>
    </div>
  </form>
</dialog>
document.querySelector("#modal-sair").addEventListener("close", (evento) => {
  if (evento.target.returnValue === "cancelar") {
    Atalho.notificar("Subscrição cancelada.", { tipo: "aviso" });
  }
});

      <div class="at-campo">

      </div>

const campo = document.querySelector("#confirma-nome");
const botao = document.querySelector("#botao-excluir");
const modal = document.querySelector("#modal-excluir");

campo.addEventListener("input", () => {
  botao.disabled = campo.value !== "loja-virtual";
});

modal.addEventListener("close", () => {
  if (modal.returnValue === "excluir") {
    Atalho.notificar("Projeto eliminado.", { tipo: "perigo" });
  }
  campo.value = "";
  botao.disabled = true;
  modal.returnValue = "";
});

Acessibilidade

  • Dê um título ao modal e ligue com aria-labelledby.
  • O foco vai para dentro do modal ao abrir e volta para o botão ao fechar (o navegador faz isso).
