Instalação

Duas linhas no seu HTML e todos os componentes funcionam. Sem npm, sem build, sem configuração.

HTML
Padrão usado emBootstrap (uso por CDN)Alpine.js (atributos no HTML)
Suporte dos navegadoresJavaScript modules · Em todos os navegadoresCustom properties · Em todos os navegadores<dialog> · Em todos os navegadoresPopover · Novo em todos os navegadores

Quando usar

  • Em qualquer página HTML, do primeiro projeto do curso ao sistema da empresa.
  • Quando quer um resultado profissional sem montar um ambiente com Node, React e bundler.

Como funciona

O CSS traz o visual de todos os componentes. O JavaScript observa a página e liga sozinho tudo o que tiver atributos data-at-..., inclusive HTML que chegar depois via fetch. Não precisa de chamar nenhuma função de inicialização. Use defer nos scripts: são executados pela ordem em que aparecem, depois de o HTML terminar de carregar.

Exemplos

Página mínima

Copie, guarde como index.html e abra no navegador. Pronto.

<!doctype html>
<html lang="pt-PT">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>O meu projeto</title>

  <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/marcos-zorzetto/atalho@1/atalho/atalho.css">
  <script src="https://cdn.jsdelivr.net/gh/marcos-zorzetto/atalho@1/atalho/atalho.js" defer></script>
  <!-- O seu código depois do Atalho, também com defer -->
  <script src="app.js" defer></script>
</head>
<body>
  <main class="at-container at-secao">
    <h1 class="at-titulo-2">Olá, mundo</h1>
    <button class="at-botao at-primario" data-at-notificar="Funcionou!">
      Clique aqui
    </button>
  </main>
</body>
</html>

A testar agora

O mesmo botão do exemplo acima, a correr nesta página.

Editar e testar

Descarregar os ficheiros (sem internet)

Se preferir não depender de CDN, descarregue atalho.css e atalho.js do GitHub e aponte para a sua pasta.

<link rel="stylesheet" href="css/atalho.css">
<script src="js/atalho.js" defer></script>

Referência

NomeTipoO que faz
atalho.cssficheiroEstilos de todos os componentes. Classes começam com at-.
atalho.jsficheiroComportamentos. Cria o objeto global window.Atalho.
data-at="..."atributoLiga um componente com comportamento (abas, tabela, kanban...).
at:prontoeventoDisparado no document quando o Atalho terminou de ligar a página.

Acessibilidade

  • Mantenha lang="pt-PT" no <html> (ou "pt-BR", "en"): os leitores de ecrã usam isso para pronunciar o texto, e o Atalho escolhe o idioma das mensagens e a moeda (euro, ou real no pt-BR).
  • O meta viewport é obrigatório para o site funcionar bem no telemóvel.
