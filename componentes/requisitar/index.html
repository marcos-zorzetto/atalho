Obter dados de uma API

fetch com tempo limite, JSON automático e erros em português. Com o Estado, ganha os estados de carregamento, erro e resultado no ecrã sem esforço.

HTMLJavaScriptTypeScriptPHP
Padrão usado emAxios (erros e tempo limite)TanStack Query (estados de carregamento/erro/sucesso)
Suporte dos navegadoresFetch · Em todos os navegadoresAbortable fetch · Em todos os navegadoresAbortController and AbortSignal · Em todos os navegadores

Quando usar

  • Sempre que a página precisa de falar com um servidor.

Como funciona

Atalho.requisitar(url, opções) devolve os dados já convertidos de JSON. Se der erro, lança uma mensagem pronta para mostrar à pessoa ("Sem ligação à internet", "O servidor demorou demasiado"). Passe corpo como objeto e é convertido em JSON; passe um FormData para enviar ficheiros.

Pesquisa enquanto escreve

Dados reais da API pública DummyJSON (preços fictícios). Tente "phone", "watch" ou "shoes".

let controle;

const catalogo = Atalho.estado("catalogo", {
  produtos: [],
  carregando: false,
  erro: "",
  status: "",

  async buscar(termo) {
    controle?.abort(); // cancela a pesquisa anterior se a pessoa continuar a escrever
    controle = new AbortController();
    this.carregando = true;
    this.erro = "";

    try {
      const url = "https://dummyjson.com/products/search?limit=6&select=title,price,thumbnail&q=" + encodeURIComponent(termo);
      const resposta = await Atalho.requisitar(url, { sinal: controle.signal });
      this.produtos = resposta.products;
      this.status = Atalho.formatar.plural(resposta.total, "produto encontrado", "produtos encontrados");
    } catch (erro) {
      if (erro.name === "AbortError") return;
      this.produtos = [];
      this.erro = erro.message;
    }
    this.carregando = false;
  },
});

catalogo.buscar("watch");

Enviar (POST) e tratar erro

<script>
  async function salvarCliente(dados) {
    try {
      const cliente = await Atalho.requisitar("/api/clientes", {
        metodo: "POST",
        corpo: dados,
        cabecalhos: { Authorization: "Bearer " + token },
      });
      Atalho.notificar("Cliente " + cliente.nome + " registado.", { tipo: "sucesso" });
    } catch (erro) {
      // erro.message já vem em português: "Verifique os dados do formulário."
      Atalho.notificar(erro.message, { tipo: "perigo" });
      console.log(erro.status, erro.dados); // 422, { campo: "email", ... }
    }
  }
</script>
interface Cliente { id: number; nome: string }

async function salvarCliente(dados: Omit<Cliente, "id">, token: string): Promise<void> {
  try {
    const cliente = await Atalho.requisitar<Cliente>("/api/clientes", {
      metodo: "POST",
      corpo: dados,
      cabecalhos: { Authorization: `Bearer ${token}` },
    });
    Atalho.notificar(`Cliente ${cliente.nome} registado.`, { tipo: "sucesso" });
  } catch (erro) {
    if (erro instanceof Error) Atalho.notificar(erro.message, { tipo: "perigo" });
  }
}

metodoopção"GET" (predefinido), "POST", "PUT", "PATCH", "DELETE".
corpoopçãoObjeto (convertido em JSON) ou FormData.
cabecalhosopçãoEx.: { Authorization: "Bearer ..." }.
