Enviar ficheiros

Área para arrastar e largar ficheiros, com pré-visualização das imagens, tamanho formatado, botão de remover e limite de tamanho.

HTMLJavaScriptPHP
Padrão usado emGoogle DriveWeTransferNotion (anexos)
Suporte dos navegadores<input type="file"> · Em todos os navegadores<input type="file" multiple> · Em todos os navegadoresDrag and Drop · Em todos os navegadoresFile API · Em todos os navegadores

Quando usar

  • Envio de documentos, fotos de produtos, comprovativos.

Como funciona

É um <input type="file"> de verdade dentro de um <label>: clicar abre o seletor, e arrastar também funciona. O Atalho mostra a lista em .at-upload-lista (logo depois da área, ou onde data-lista indicar). Para enviar ao servidor, use FormData com o próprio formulário.

    <?php
// api/upload.php — confere o tipo REAL do ficheiro, não a extensão
require __DIR__ . '/atalho.php';
use function Atalho\{exigirMetodo, salvarUpload, responderErro, responderJson};

exigirMetodo('POST');
try {
    $nome = salvarUpload($_FILES['foto'], __DIR__ . '/uploads', ['image/jpeg', 'image/png', 'image/webp'], 5);
    responderJson(['arquivo' => $nome], 201);
} catch (RuntimeException $erro) {
    responderErro($erro->getMessage(), 422);
}

    Referência

    NomeTipoO que faz
    data-at="upload"atributoNo <label class="at-upload">.
    data-tamanho-maximo="5"atributoLimite em MB por ficheiro (avisa se passar).
    data-lista="#id"atributoOnde mostrar a lista (por omissão: o elemento seguinte).
    at:arquivoseventoFicheiros escolhidos. detail.arquivos é uma lista de File.

    Acessibilidade

    • Como é um input real, funciona com teclado (Tab + Enter) e leitores de ecrã, o que muitas áreas de arrastar feitas só com div não fazem.
