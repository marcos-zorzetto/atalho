Botão

Botões para cada nível de importância, tamanhos, ícones, estado de a carregar, grupo e contador.

HTMLJavaScript
Padrão usado emGitHub (Primer)Stripe DashboardShopify Polaris

Quando usar

  • at-primario: a ação principal do ecrã. Uma só por área.
  • Botão normal (sem modificador): ações secundárias.
  • at-fantasma ou at-link: ações discretas, como Cancelar.
  • at-perigo: eliminar, cancelar subscrição. Sempre com confirmação.

Evite

  • <div> ou <a> clicável no lugar de <button>: não funciona com teclado nem com leitor de ecrã.

Como funciona

Use <button> para ações e <a class="at-botao"> para navegação (ir para outra página). Para mostrar que algo está a carregar, coloque aria-busy="true": o texto dá lugar a um indicador a girar e o botão deixa de aceitar cliques, o que evita pedidos duplicados.

A carregar ao guardar

Editar e testar 
<button class="at-botao at-primario" id="botao-salvar">Guardar</button>
const botao = document.querySelector("#botao-salvar");

botao.addEventListener("click", () => {
  botao.setAttribute("aria-busy", "true");

  setTimeout(() => {
    botao.removeAttribute("aria-busy");
    Atalho.notificar("Alterações guardadas.", { tipo: "sucesso" });
  }, 1500);
});

Grupo e contador

Editar e testar 
<div class="at-linha">
  <div class="at-grupo-botoes" role="group" aria-label="Período">
    <button class="at-botao" aria-pressed="false">Dia</button>
    <button class="at-botao" aria-pressed="true">Semana</button>
    <button class="at-botao" aria-pressed="false">Mês</button>
  </div>

  <button class="at-botao at-icone at-contador-selo" aria-label="Notificações: 3 novas">
    <svg viewBox="0 0 24 24" width="18" height="18" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="M6 16v-5a6 6 0 0 1 12 0v5l2 2H4z"/><path d="M10 21h4"/></svg>
    <span data-contador aria-hidden="true">3</span>
  </button>
</div>
document.querySelectorAll("[aria-label='Período'] .at-botao").forEach((botao, _, todos) => {
  botao.addEventListener("click", () => {
    todos.forEach((b) => b.setAttribute("aria-pressed", String(b === botao)));
  });
});

Referência

NomeTipoO que faz
at-botaoclasseBase.
at-primario / at-suave / at-perigo / at-sucesso / at-fantasma / at-linkclasseVariações.
at-pequeno / at-grande / at-bloco / at-iconeclasseTamanhos e formatos.
aria-busy="true"atributoEstado a carregar.
at-grupo-botoesclasseBotões colados. Marque o ativo com aria-pressed="true".
at-contador-selo + [data-contador]classeNúmero sobre o botão (carrinho, notificações).
data-at-notificar="texto"atributoMostra uma notificação ao clicar (atalho rápido).

Acessibilidade

  • Botão só com ícone precisa de aria-label a descrever a ação.
  • Em grupos de alternância (Dia/Semana/Mês), use aria-pressed.
