# Atalho para VS Code

Componentes prontos **em português** dentro do seu editor. Digite `at-`, escolha e pronto: o código aparece já formatado, acessível e responsivo.

A extensão é **grátis com uma conta do Atalho** (a mesma do site). Crie a sua em [marcos-zorzetto.github.io/atalho/conta](https://marcos-zorzetto.github.io/atalho/conta/?criar).

## O que você recebe

| | Conta grátis | Pro |
|---|:---:|:---:|
| Trechos da biblioteca (`at-modal`, `at-tabela`, `at-hero`…): mais de 100 | ✓ | ✓ |
| Autocompletar das classes dentro de `class="…"` | ✓ | ✓ |
| Dica com link para a documentação ao passar o mouse | ✓ | ✓ |
| Componentes avançados (`atx-…`) | 20 | **todos (119)** |
| Animações editáveis (`anim-…`) | 10 | **todas (48)** |
| Painel lateral com busca por categoria | ✓ | ✓ |

## Como usar

1. Instale a extensão e clique no ícone do **Atalho** na barra lateral.
2. Clique em **Entrar** (ou **Criar conta grátis**).
3. Abra um arquivo `.html` e digite `at-`. Use as setas e aperte **Enter**.

Outros jeitos de inserir:

- **Painel lateral:** clique no componente para colar onde está o cursor.
- **Busca:** `Ctrl+Shift+P` → *Atalho: Inserir componente* e escreva o que procura ("carrinho", "agenda", "entrada suave").
- **Página nova:** `Ctrl+Shift+P` → *Atalho: Nova página com o Atalho* cria o HTML com o CSS e o JavaScript já ligados.

Os componentes avançados e as animações já vêm com o CSS e o JavaScript juntos. As cores e tamanhos ficam em variáveis no começo do CSS (`--nome-cor`, `--nome-duracao`), fáceis de trocar.

## Funciona em

HTML, PHP, Vue, Svelte, Astro, Blade, Django, Handlebars e ERB.

## Privacidade e segurança

- O login usa a sua conta do Atalho. A senha vai direto para o servidor de login e **não fica guardada**.
- A extensão guarda só um código de sessão, no cofre de segredos do próprio VS Code. *Atalho: Sair da conta* apaga esse código.
- Nada do seu código é enviado para lugar nenhum.
