    Os dois cartões acima são componentes do Atalho, conectados pelo estado. Nenhum framework.

    “Eu desisti de programar mais de uma vez. Não foi por falta de vontade.”

    Eu assistia a um tutorial e entendia uma coisa. Assistia a outro e entendia outra. Na hora de juntar tudo num projeto de verdade, nada se encaixava. E a documentação oficial ajudava pouco: boa parte só existe em inglês e mostra cada peça isolada, nunca a tela pronta.

    O Atalho é o material que eu queria ter tido no começo. Cada componente vem completo, resolvido do jeito que as empresas grandes resolvem, com a explicação em português, os erros que se deve evitar, a acessibilidade e, principalmente, como ele se conecta com os outros para virar uma tela de verdade.

    — Marcos Zorzetto

    Como funciona

    Três passos. Nenhuma instalação.

    Cole duas linhas

    No <head> de qualquer página. Sem npm, sem build, sem configurar nada.

    <link rel="stylesheet" href=".../atalho.css">
<script src=".../atalho.js" defer></script>

    Copie o componente

    O comportamento vem de atributos em português. O exemplo é o mesmo código que roda na página.

    <input class="at-entrada"
       data-at-mascara="cpf">

<button commandfor="confirmar"
        command="show-modal">Excluir</button>

    Conecte com o estado

    Mude os dados e a tela inteira acompanha. A ideia do React, sem precisar do React.

    const carrinho = Atalho.estado("carrinho", {
  itens: [],
  get total() { /* ... */ },
});

<!-- Atualiza sozinho: -->
<span data-at-texto="carrinho.total">

    Atualizado sozinho

    A documentação muda. O Atalho acompanha.

    Toda semana, um robô no GitHub confere os dados oficiais de suporte dos navegadores (os mesmos dos selos Baseline do MDN) e todos os links da documentação. Quando um recurso chega a todos os navegadores, um link quebra ou uma página ganha tradução para português, ele abre uma proposta de atualização e o Claude sugere as mudanças nos componentes.
