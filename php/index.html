PHP no servidor

O navegador facilita a vida de quem preenche; o servidor protege os seus dados. Tudo o que o Atalho valida no navegador deve ser validado de novo no PHP.

Regra de ouro

Nunca confie no que vem do navegador. Qualquer pessoa pode desligar o JavaScript ou enviar dados diretamente para a sua API.

1. Descarregue a biblioteca PHP

Um ficheiro só, sem dependências, para PHP 8.1 ou mais recente: atalho.php.

Terminal
curl -o atalho.php https://cdn.jsdelivr.net/gh/marcos-zorzetto/atalho@1/php/atalho.php

2. O que vem nela

FunçãoO que faz
validarNif($nif)Verifica o dígito de controlo do NIF/NIPC de Portugal (com ou sem espaços).
validarIban($iban)IBAN de qualquer país da Europa (tamanho por país e módulo 97).
validarEmail / validarTelefone / validarTelemovel / validarCodigoPostalValidações comuns, com as mesmas regras do navegador.
validarCpf / validarCnpj / validarCepDocumentos do Brasil, para quem também vende para lá (CNPJ alfanumérico incluído).
validar($dados, $regras)Valida vários campos e devolve as mensagens de erro em português.
lerJson()Lê o JSON enviado pelo navegador, com limite de tamanho.
responderJson($dados, $status)Responde em JSON com o cabeçalho certo e encerra.
responderErro($mensagem, $status, $campos)Erro no formato { erro, campos } que o Atalho entende.
exigirMetodo('POST')Recusa outros métodos HTTP.
cors($origens)Permite chamadas só dos domínios indicados.
iniciarSessao() / tokenCsrf() / validarCsrf()Sessão com cookie seguro e proteção contra CSRF.
buscarCodigoPostal($cp)Morada de um código postal português (GEO API PT), com cache em ficheiro.
buscarCep($cep)Endereço de um CEP do Brasil (ViaCEP), com cache em ficheiro.
salvarUpload($arquivo, $pasta, $tipos, $mb)Guarda o upload, verificando o tipo real do ficheiro e gerando um nome aleatório.
paginar($total, $pagina, $porPagina)Calcula página, deslocamento e total de páginas.
formatarMoeda($valor, $moeda)1234,50 € (euro por omissão; 'BRL' para R$). Também formatarCpf e formatarCnpj.
e($texto)Escapa texto para HTML. Use sempre ao imprimir dados do utilizador (evita XSS).

3. Receber um formulário

O navegador valida para ajudar quem preenche; o PHP valida de novo para proteger o sistema. Erros voltam por campo, no mesmo formato das mensagens do Atalho.

HTML (navegador)
<form id="cadastro" data-at-validar>…</form>

<script>
  document.querySelector("#cadastro").addEventListener("at:enviar", async (evento) => {
    const { dados, botao } = evento.detail;
    botao.setAttribute("aria-busy", "true");
    try {
      const cliente = await Atalho.requisitar("api/cadastro.php", { metodo: "POST", corpo: dados });
      Atalho.notificar("Bem-vindo(a), " + cliente.nome + "!", { tipo: "sucesso" });
    } catch (erro) {
      Atalho.notificar(erro.dados?.erro || erro.message, { tipo: "perigo" });
    } finally {
      botao.removeAttribute("aria-busy");
    }
  });
</script>
api/cadastro.php
<?php
// api/cadastro.php — recebe o formulário enviado pelo evento at:enviar
declare(strict_types=1);

require __DIR__ . '/../atalho.php';

use function Atalho\{exigirMetodo, lerJson, validar, responderErro, responderJson, somenteDigitos, limparTexto};

exigirMetodo('POST');
$dados = lerJson();

// As mesmas regras do navegador, conferidas de novo no servidor
$erros = validar($dados, [
    'nome' => ['obrigatorio', 'min:3', 'max:120'],
    'email' => ['obrigatorio', 'email'],
    'nif' => ['obrigatorio', 'nif'],
    'telemovel' => ['obrigatorio', 'telemovel'],
]);

if ($erros) {
    responderErro('Verifique os dados do formulário.', 422, $erros);
}

$cliente = [
    'nome' => limparTexto($dados['nome'], 120),
    'email' => mb_strtolower(trim($dados['email'])),
    'nif' => somenteDigitos($dados['nif']),            // guarde só os algarismos
    'telemovel' => somenteDigitos($dados['telemovel']),
];

// Aqui guardaria na base de dados (veja o exemplo de pedidos com PDO)
responderJson(['id' => 123, 'nome' => $cliente['nome']], 201);

4. Código postal pelo seu servidor

Útil quando quer guardar em cache, registar consultas ou não depender do navegador para falar com a GEO API PT. Há também buscarCep() para o Brasil.

api/codigo-postal.php
<?php
// api/codigo-postal.php?cp=1250-096 — morada pelo código postal (GEO API PT), com cache
declare(strict_types=1);

require __DIR__ . '/../atalho.php';

use function Atalho\{exigirMetodo, buscarCodigoPostal, responderErro, responderJson, validarCodigoPostal};

exigirMetodo('GET');
$codigo = (string) ($_GET['cp'] ?? '');

if (!validarCodigoPostal($codigo)) {
    responderErro('Código postal inválido (formato 0000-000).', 422);
}

try {
    $morada = buscarCodigoPostal($codigo, __DIR__ . '/cache-cp');
} catch (RuntimeException $erro) {
    responderErro($erro->getMessage(), 503);
}

$morada ?? responderErro('Código postal não encontrado.', 404);

header('Cache-Control: public, max-age=86400');
responderJson($morada);

5. Upload seguro de imagens

Nunca confie na extensão do nome do ficheiro: um .jpg pode ser um script. A biblioteca verifica o tipo real e gera um nome aleatório.

api/upload.php
<?php
// api/upload.php — recebe as fotos do componente "Enviar ficheiros"
declare(strict_types=1);

require __DIR__ . '/../atalho.php';

use function Atalho\{exigirMetodo, validarCsrf, salvarUpload, responderErro, responderJson};

exigirMetodo('POST');
validarCsrf();

$fotos = $_FILES['fotos'] ?? null;
if (!$fotos || !is_array($fotos['name'])) {
    responderErro('Nenhuma foto enviada.', 422);
}

$salvas = [];
foreach (array_keys($fotos['name']) as $i) {
    $arquivo = [
        'name' => $fotos['name'][$i],
        'tmp_name' => $fotos['tmp_name'][$i],
        'size' => $fotos['size'][$i],
        'error' => $fotos['error'][$i],
    ];
    try {
        // Confere o tipo REAL do ficheiro, não a extensão do nome
        $salvas[] = salvarUpload($arquivo, __DIR__ . '/uploads', ['image/jpeg', 'image/png', 'image/webp'], 5);
    } catch (RuntimeException $erro) {
        responderErro("{$arquivo['name']}: {$erro->getMessage()}", 422);
    }
}

responderJson(['arquivos' => $salvas], 201);

6. Login com sessão

Palavra-passe sempre com password_hash, comparação com password_verify, nova sessão após o login e limite de tentativas.

api/login.php
<?php
// api/login.php — login com sessão segura, palavra-passe com hash e limite de tentativas
declare(strict_types=1);

require __DIR__ . '/../atalho.php';

use function Atalho\{exigirMetodo, lerJson, iniciarSessao, validarCsrf, responderErro, responderJson};

exigirMetodo('POST');
iniciarSessao();
validarCsrf();

// Limite simples: 5 tentativas a cada 15 minutos por sessão
$tentativas = array_filter($_SESSION['tentativas'] ?? [], fn (int $hora) => $hora > time() - 900);
if (count($tentativas) >= 5) {
    responderErro('Demasiadas tentativas. Aguarde 15 minutos.', 429);
}

$dados = lerJson();
$email = mb_strtolower(trim((string) ($dados['email'] ?? '')));
$senha = (string) ($dados['senha'] ?? '');

// Procure o utilizador na base de dados. Ao registar, guarde: password_hash($senha, PASSWORD_DEFAULT)
$usuario = buscarUsuarioPorEmail($email);

// password_verify compara com o hash em tempo constante
if (!$usuario || !password_verify($senha, $usuario['senha_hash'])) {
    $_SESSION['tentativas'] = [...$tentativas, time()];
    responderErro('E-mail ou palavra-passe incorretos.', 401); // não diga qual dos dois errou
}

session_regenerate_id(true); // evita sequestro de sessão
unset($_SESSION['tentativas']);
$_SESSION['usuario_id'] = $usuario['id'];

responderJson(['nome' => $usuario['nome']]);

/** Exemplo: troque pela consulta à sua base de dados. */
function buscarUsuarioPorEmail(string $email): ?array
{
    $exemplo = ['id' => 1, 'nome' => 'Ana', 'email' => 'ana@exemplo.com', 'senha_hash' => password_hash('senha-de-teste', PASSWORD_DEFAULT)];
    return $email === $exemplo['email'] ? $exemplo : null;
}

7. Lista paginada com base de dados

JSON paginado para alimentar a Tabela de dados, com PDO e parâmetros para evitar SQL injection.

api/pedidos.php
<?php
// api/pedidos.php?pagina=1&busca=maria — lista paginada para a Tabela de dados
declare(strict_types=1);

require __DIR__ . '/../atalho.php';

use function Atalho\{exigirMetodo, paginar, limparTexto, responderJson};

exigirMetodo('GET');

$pdo = new PDO('mysql:host=localhost;dbname=loja;charset=utf8mb4', 'utilizador', 'palavra-passe', [
    PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
]);

$busca = limparTexto($_GET['busca'] ?? '', 100);
$filtro = '%' . $busca . '%';

// Use sempre parâmetros (?), nunca junte texto do utilizador no SQL: evita SQL injection
$contar = $pdo->prepare('SELECT COUNT(*) FROM pedidos WHERE cliente LIKE ?');
$contar->execute([$filtro]);
$pagina = paginar((int) $contar->fetchColumn(), (int) ($_GET['pagina'] ?? 1), 20);

$consulta = $pdo->prepare(
    'SELECT id, cliente, status, total, criado_em
       FROM pedidos
      WHERE cliente LIKE ?
      ORDER BY criado_em DESC
      LIMIT ? OFFSET ?'
);
$consulta->bindValue(1, $filtro);
$consulta->bindValue(2, $pagina['porPagina'], PDO::PARAM_INT);
$consulta->bindValue(3, $pagina['deslocamento'], PDO::PARAM_INT);
$consulta->execute();

responderJson(['pedidos' => $consulta->fetchAll(), 'paginacao' => $pagina]);
