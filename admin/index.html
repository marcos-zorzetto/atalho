A perguntar ao servidor se a loja já está ligada…

  1. Na app ou em business.revolut.com: Merchant → ative a conta de comerciante (a Revolut aprova em 1 a 3 dias úteis).
  2. Merchant → API → Production API Secret key → gere a chave (começa por sk_).
  3. No Supabase: Edge Functions → Secrets → Add new secret com o nome REVOLUT_SECRET_KEY e a chave como valor. Nunca a envie por e-mail ou chat.
  4. Volte aqui e carregue em Ligar a loja: os planos de 9 €/mês e 79 €/ano e o webhook são criados sozinhos.
