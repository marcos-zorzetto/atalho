Atalho Pro

44 sistemas completos, prontos a instalar

CRM, marcações, orçamentos, loja, reservas, helpdesk, inventário e muito mais. Instala num passo em qualquer alojamento com PHP, sem base de dados para configurar, tudo em português de Portugal.

  1. Descarregue o zip do sistema que quer (com o Pro).
  2. Envie para o alojamento e extraia (no cPanel: File Manager → Upload → Extract).
  3. Abra o endereço, escreva o nome do negócio e a sua palavra-passe. Pronto, com dados de exemplo.
  4. Ajuste ao seu negócio em Personalizar: nomes, campos, opções e textos da página pública, sem programar.

Feito para Portugal

NIF, IBAN, código postal, +351, euro e IVA a 23, 13 e 6%. MB WAY, Multibanco e transferência nas instruções de pagamento.

RGPD de origem

Consentimento nos formulários, histórico de quem fez o quê, exportação dos dados de uma pessoa e anonimização com um clique.

Seguro

Palavras-passe cifradas, proteção CSRF, limite de tentativas, cabeçalhos de segurança e base de dados fechada ao navegador.

Testado a sério

Cada sistema é instalado e percorrido página a página num PHP 8.1 real e num navegador, com auditoria de acessibilidade, a cada mudança.

Os sistemas de faturação emitem orçamentos e faturas pró-forma; a fatura com valor fiscal sai do seu programa certificado pela AT.
